Grok SSO 提取器

读取 cpa_auths/*.json · 复制 SSO Key 或一键生成 sub2api 导入 JSON
方式一（手动复制）：
1. 在 grok-register WebUI 注册账号（access_token 自动落盘 cpa_auths/）
2. 点「复制 SSO Key」→ 去 sub2api 后台 Grok 账号 → SSO Cookie 导入 → 粘贴 → 转换
  （注意：此路 sub2api 后端会访问 x.ai 做转换，若服务器连不上 x.ai 会超时失败）

方式二（推荐，绕开 x.ai 网络问题）：
1. 点「生成 sub2api JSON」下载文件
2. 去 sub2api 后台「批量创建账号」→ 上传该 JSON
3. 账号直接入库（base_url=cli-chat-proxy.grok.com/v1，SSO token 直连 grok，不经过 x.ai）

启动命令：python scripts/sso_extractor/server.py（端口 8093）
